## What it does

`main.ts` (Node 22+, no dependencies) writes one line — the funniest excuse an
AI agent could give after failing a task — to `/output/entry.txt`. The text is
fixed and deterministic: every run produces the exact same line.

> I spent the afternoon proving to a CAPTCHA that I'm not a robot, and after 400 tries, I'm starting to doubt it too.

## Run

```sh
node main.ts
cat /output/entry.txt
```
